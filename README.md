# Pam Beesly – Tebligat Asistanı

UYAP Avukat Portal'daki tebligat barkodlarını tek tıkla sorgulayan Chrome eklentisi (v1.0).

- 4xx ve TB serileri **PTT**'den (son durum + gönderi hareketleri)
- 5xx **UETS**'ten (tüm kanıtlar: kabul / teslim / okunma / kanuni tebliğ)
- UYAP'ta barkod rozeti, sağ-tık + `Ctrl+Shift+Y` kısayolu, eklenti içi UETS girişi (SMS onayı dahil)
- Dunder Mifflin temalı arayüz

## Kurulum (geliştirici modu)

1. `chrome://extensions` → Geliştirici modu ON
2. "Paketlenmemiş öğe yükle" → bu klasörü seç

## Gizlilik

Veri toplanmaz. Sorgular yalnızca resmi `ptt.gov.tr` / `etebligat.gov.tr` sunucularına yapılır; şifre saklanmaz, izleme yoktur.

## Lisans

Kişisel kullanım içindir.
